### 3.1 数据层

| # | 约束 | 错误来源 |
| --- | --- | --- |

| H2 | 手写倒序数组只 `ORDER BY ord`，不叠 `DESC` | 结直肠 parity ③（造口日记二次反转） |

### 3.4 医学口径（本癌种最容易越界的地方）

| # | 约束 | 错误来源 / 依据 |
| --- | --- | --- |
| M1 | **分级只用「对照」**，写「1 级 · >1.0–3.0 ×ULN · 实测 2.4×ULN」，不写"偏高/偏低/严重"，不推断因果、不给处置 | starter `docs/23` §2 |
| M2 | ×ULN 型（ALT/AST/ALP/GGT/总胆红素/肌酐）**必须用这张化验单自带的 `ref_high`**；缺了返回 `needsUln` + 虚线徽章「需参考上限」，绝不借成人通用上限（ALT 各室 40–55，差 1.4 倍，一除能把 2 级说成 1 级） | 家族「下限可以借，上限不能借」 |
| M3 | **CA19-9 不做分级**：CTCAE 没有它的分级条目，也没有公认阈值 → 只做趋势线 + 参考范围对照，不给徽章。硬凑分级是最典型的"借数据" | 本癌种特有 |
| M4 | **黄疸/梗阻只能记「观察项」，不能判「是不是急症」**：记录体温、引流量、颜色、尿色、陶土便、瘙痒；页面只写「出现这些情况该联系医疗团队」，**不写处置、不写分诊等级** | 家族红线：只整理不给建议 |
| M5 | **可切除性只能记「谁说的、哪天说的、原话要点」**，不写「可以切除 / 不能切除」的判定，不做 BCLC 式自动归类。肝门部按 Bismuth-Corlette 分型是**解剖分型**，不是可切除结论 | 肝族 BCLC/CNLC 教训延伸 |
| M6 | 分型术语固定四种，不许混用：胆囊癌（GBC）/ 肝内胆管癌（iCCA）/ 肝门部胆管癌（pCCA，附 Bismuth-Corlette）/ 远端胆管癌（dCCA）。**壶腹癌不在本项目范围**（backlog #18，挂小肠/胆道） | 防"分期/分型"混写 |
| M7 | 治疗与靶点线索只作**记录字段**（是否用过、是否检测过），不写「推荐/首选/应该用」；药物按分型写成"某分型常见的检测位点"，不写成用药建议 | 家族红线词表 |
| M8 | 指南只做「出处 + 节奏 + 并列口径」，处置推荐只折叠原文，不改写成产品语句；未采用的原文分支要写「未采用」及原因。**每条指南条目必须同时有机构 + 版本 + 页码，缺任一项整条不显示（显示「未引入」），不许占位猜** | starter `docs/25` |
| M9 | **「病人病情怎么样了」只答事实，不答好坏**：`dash` 现状卡四行（关键指标值/日期/与上次差/参考范围、影像结论原文引用、当前治疗周期、医生说的分期与可切除性 + 谁说的哪天）模板填空，**禁用词表**：稳定、好转、恶化、进展、缓解、良好、不乐观、预后、控制住了、问题不大。搜到任一即判不通过 | U6 输入（2026-10-24）：「太多报告看不懂，病人病情怎么样了？」——这句字面在要结论，产品线划在"答事实不答判读" |
| M10 | **报告只做索引，不做解读**：每份文件一行（日期/类型/谁开的/结果原文首行/是否进趋势）；可给**检查项目本身的通用说明**，但必须同屏写明「说明的是检查项目，不是你的结果」。不写"报告说没事/有问题"，不接 AI 读片 | 同上；与 A8 配套 |
| M11 | **三层信息边界（最高约束）**：① 事实（值/日期/谁说的/差值）——可做，须能点回来源；② 解释（指标是什么、检查查什么、指南原文、CTCAE 表怎么规定）——可做，须带机构+版本+页码，通用说明同屏注明"不是你的结果"；③ 判断（好坏/稳定/进展/方案优劣/停药/是否复发/预后）——**一句都不生成**，固定出口「这一句需要问你的医生」。**提醒属第 ② 层**，触发条件必须来自用户自己的记录或日期，写法三样缺一不可：陈述事实 + 指明这是谁的标准 + 指向医生；禁「应/需/建议/警惕/注意排除」 | 2026-10-24 维护者确认原话：「医疗结论是医生的判断，信息解释和提醒是工作台提供的支持能力。」M9 / M10 是本条的实例 |
| M12 | **总胆红素（TBIL）与直接胆红素（DBIL）不得混称**：界面任何位置只说"总胆红素"或"直接胆红素"，不写孤立"胆红素"；两者分别记录、分别显示、不互相替代；同一张单上 `direct_bilirubin <= total_bilirubin`，库层 `CHECK` 兜底。差值只能作为算术结果展示，不得据此推断病因 | 维护者 2026-10-24 原话：「胆红素和总胆红素不可能一样」 |
| M13 | **临床试验只做「条件对照」，不做入组判断**：① 每条条件三态（符合 / 不符合 / 待确认），未知项保留为待确认，不得用阴性或符合填充；② 硬性条件不满足的单列，不混进推荐序；③ 符合度 = 符合项 ÷ 已对照项，未知按 0 计并同屏写明"只会偏低、不是入组资格、不代表效果"；④ 条目必须带登记号、状态、核验日期，没有核验日期只能显示「未核验」；⑤ 收藏跟踪只记外部注册信息变化，不预测结果、不替用户决定 | 维护者 2026-10-24 要求补齐临床试验匹配（病理特点 → 自动符合度 → 收藏跟踪） |

> **M11 的适用范围**：本项目 + 之后新建的病种工作台。已有工作台不回溯改造（2026-10-24 维护者决定）。
