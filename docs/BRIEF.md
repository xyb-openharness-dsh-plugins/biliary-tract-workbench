# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：胆道癌患者与家属（含术后带引流管居家照护者、接受系统治疗者）、以及协助整理的照护者

场景：确诊后要弄清「我是哪一型、还能不能切、现在这条治疗是第几线」；带管居家期间要记黄疸与引流量；每次复查前要把指标趋势和想问的问题整理出来

核心流程：
1. 建档：录入分型（胆囊/肝内/肝外）、分期与可切除性结论出处，明确哪些是医生说的、哪些是自己理解的
2. 记录：黄疸相关指标与症状、胆道引流（PTCD/ENBD/支架）日常、治疗线序与不良反应
3. 准备：复查前生成指标趋势视图与一份「这次想问医生的问题」清单

完成结果：患者能在一次复查前说清「我这一型现在处在哪条路径、这半年指标怎么走、这次要问哪 5 个问题」，并把这份整理交给医生

初始布局选择：business-first
