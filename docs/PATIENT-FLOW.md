# 患者流程（PATIENT-FLOW）

> 四条流程都**不是**从医生诊疗路径照搬，而是从"患者在哪一刻最难受"倒推页面。
> 标 **U1–U6 用户假设**（U = User assumption）。**U1–U4 尚未经任何访谈核实；U5、U6 在 2026-10-24 收到一条非正式输入（n=1，来源为对话输入，未记录身份、未区分患者本人或家属），只够改方向，不够算核实。**
>
> **三层信息边界（全项目最高约束）**：事实与解释可做，判断一律不做；提醒的触发条件必须来自用户自己的记录或日期，不能来自对病情的判断。详见 `SPEC.md` §零 与硬约束 M11。
>
> **三套编号不要混**：`U1–U6` = 用户假设（本文件）｜`H1–H21` = 硬约束（`DEV-REQUIREMENTS-2026-10-24.md`）｜`M1–M11` = 医学口径（同上）。

## 流程 A：确诊后的两周——"我这是哪一型，还能不能切"

| 时刻 | 患者的状态（假设 U1） | 打开哪一页 | 得到什么产物 |
| --- | --- | --- | --- |
| 刚拿到病理/影像报告 | 报告上写「胆管细胞癌」「肝门部占位」「考虑胆道来源」，四个名词混着出现，不知道是不是一回事 | `type` 分型与可切除性 | 一张**分型卡**：把自己报告里的词对应到四种分型之一（GBC / iCCA / pCCA / dCCA）；每型下面写"这个词通常指什么"，不做判断 |
| 医生说了"先减黄"或"可以考虑手术"，但没听懂条件 | 记住了结论，忘了条件；家属之间说法不一致 | `type` 可切除性记录 | **三条记录位**：谁说的 / 哪天说的 / 原话要点（自由文本）。页面写「这里只记录医生说过什么，不判断能不能切」 |
| 不知道下一步该问什么 | 门诊只有 10 分钟，出来才想起三个问题没问 | `care` 就诊准备 | 一份「下次门诊要问的 8 个问题」清单（可勾选、可自己加），导出为纯文本带去门诊 |

**验收**：从 `dash` 出发，三个产物都能在 ≤3 次点击内拿到；分型卡不出现"分期"字样；可切除性页不存在任何自动判定控件。

## 流程 B：带管居家的一个晚上——"这算不算要马上回医院"

| 时刻 | 患者/家属的状态（假设 U2） | 打开哪一页 | 得到什么产物 |
| --- | --- | --- | --- |
| 引流袋里今天的量比昨天少了一半，颜色变深 | 不知道是堵了还是正常波动；夜里不敢打扰医生，又怕耽误 | `drain` 胆道引流照护 | **当日记录**：引流量(ml/24h) / 颜色（预设四档）/ 有无换药 / 体温。历史曲线只画量，不画"好/坏" |
| 有点低烧 37.8℃，皮肤更痒 | 想知道"多少度必须联系医院" | `drain` 观察项清单 | 一张**观察项表**（体温 / 引流量骤减 / 黄疸加重 / 剧烈腹痛 / 引流管脱出），每项右边只写「出现这些情况请联系你的医疗团队」，**不写处置、不写分诊等级**（硬约束 M4） |
| 第二天门诊，医生问"这几天引流量多少" | 记在纸上丢了，只能回忆 | `drain` 记录导出 | 近 7 天引流量小表 + 体温记录，一行一天，可直接给医生看 |

**验收**：`drain` 页所有文案里**没有**「建议」「应该」「立刻就医」「危险」等判定词；只有「联系你的医疗团队」这一句固定出口；体温记录能按天回看。

## 流程 C：三个月一次复查——"这半年到底怎么走的，现在到底怎么样"

> U6 已按 2026-10-24 的一条输入改写：痛点不是「会不会记引流量」，而是
> **「太多不同的检测报告看不懂，病人病情到底怎么样了？」**（原话引用见 §四）。
> 这条把一个"记录行为"假设换成了"理解现状"假设，页面重心随之从"多填一个表"移到 **`dash` 的现状卡 + `labs` 的报告清单**。

| 时刻 | 患者/家属的状态（假设 U6） | 打开哪一页 | 得到什么产物 |
| --- | --- | --- | --- |
| 复查前一周，翻手机相册找化验单 | 六次化验散在相册和纸质单里，说不清趋势（U3） | `labs` 化验 + `chart` 一图秀 | 两条数值线（总胆红素 / CA19-9）+ 治疗节点竖线；每个点可点开看原始值与参考范围 |
| **手里同时有化验、CT 报告、病理、出院小结，四类纸混在一起** | **不知道哪份是查什么的、哪份还有用；越看越乱** | `labs` 二级页签「报告」 | **报告清单**：一行一份（日期 / 类型 / 谁开的 / 结果原文首行），并标「已进趋势 / 仅存档」。每类给一句**通用说明**（"这份是查什么的"），并写明「说明的是检查项目本身，不是你的结果」 |
| **想知道"病人现在到底怎么样"** | **心里没底，又不想在家人面前问得太外行** | `dash` 现状卡 | **只填事实的四行**：最近一次关键指标（值 / 日期 / 与上次差 / 参考范围）｜最近一次影像结论原文（引用）｜当前治疗第几周期（起止）｜最近一次医生说的分期与可切除性（谁说的、哪天）。**不出现「稳定 / 好转 / 进展 / 良好」任何判断词**（硬约束 M9） |
| CA19-9 这次比上次高了 | 紧张，但不知道这个波动算不算大事 | `chart` 指标卡背面 | 卡片背面：本次值 / 参考范围 / 与上次的差；**只陈述数值**，不写"升高=进展" |
| 治疗线序记不清了 | 已经换过两次方案，忘了第一线用的什么 | `treat` 治疗线序 | 时间轴：每条线序一行（起止日期 / 方案名 / 是否仍在用），旧行不被新行覆盖（硬约束 H6） |
| 进诊室前 5 分钟 | 忘了要问什么 | `care` 就诊准备 | 同上那份清单，加上"这次的指标我看不懂的两处"——由 `labs` 里被标记"看不懂"的点自动带过来 |

**验收**：一图秀默认指标是**总胆红素**（不是 CA19-9，避免把肿瘤标志物当主指标）；卡片背面没有判读句；线序页历史行只读不可改；**`dash` 现状卡的四行全部有出处（日期 / 谁说的），且文案里搜不到 M9 的禁用词**。

## 流程 D：换方案前后——"医生为什么这么定，我看不出依据"

> U5 已按 2026-10-24 的一条输入改写：不是「家属和患者对能不能切理解不一致」，
> 而是 **「对后续治疗策略的重要指标依据、以及影响判断的依据不了解；不懂指南，不知道该怎么理解」**。

| 时刻 | 患者/家属的状态（假设 U5） | 打开哪一页 | 得到什么产物 |
| --- | --- | --- | --- |
| 门诊说"要换方案了"，理由只记住半句 | 记住了结论，没记住医生为什么这么定 | `treat` 二级「方案依据」 | **决策依据记录**，一次讨论一条，三栏：① 医生说的理由（原话）② 涉及的指标（从已记录指标里勾选，带日期与值）③ 对应的指南条目（**只有拿到带页码原件才显示**，否则写「未引入」，不许占位猜） |
| 想知道"指南上到底怎么说的" | 网上搜到的说法互相矛盾，不知道哪个可信 | `treat` 二级「方案依据」→ 指南条目 | 每条目只给：来源（机构 / 版本 / 页码）、节奏（多久评一次）、并列口径（几条平行说法一起列）。**不判断"你符合哪条"**（硬约束 M8） |
| 家属和患者各记一个版本，说法对不上 | 两个人都在场，记住的东西不一样 | 同上，按"谁记的"分栏 | 同一次讨论可存多条记录，标注来源（患者 / 家属 / 医生小结），**不合并成一条"共识"**（硬约束 H5 看法恒不为结论） |
| 想知道"这个方案适不适合我" | 心里最想问的其实是这句 | —— | **没有这个产物，也不做**。页面固定写「本工作台不判断方案是否合适，这一句需要问你的医生」 |

**验收**：`treat/依据` 页每一栏都能追到日期与出处；出现指南条目时必带版本与页码，缺任一则整条不显示；页面搜不到「推荐」「首选」「应该用」；"适不适合"类问题不产生任何自动回答。

## 页面树（由上面四条反推，不从医生流程照搬）

```
dash 看板（含「现状卡」四行事实）        ← 流程 C（U6）
├── type      分型与可切除性             ← 流程 A（U1）
├── jaundice  黄疸与胆道梗阻             ← 流程 A/B 的交界（症状 + 胆红素趋势）
├── drain     胆道引流照护（PTCD/ENBD/支架） ← 流程 B（U2）
├── treat     治疗线序与靶点检测          ← 流程 C（U4）+ 流程 D（U5）
│             二级：线序 / 方案依据 / 检测位点
├── labs      化验与报告                 ← 流程 C（U3 + U6）
│             二级：值 / 报告清单 / 我不懂的
├── imaging   影像                       ← 流程 C（U3）
├── chart     一图秀                     ← 流程 C（U3）
├── care      复查与就诊准备              ← 流程 A/C/D
└── settings  全局设置（家族统一）
```

**为什么 `jaundice` 和 `drain` 分成两页**：前者是"身体在发生什么"（症状 + 胆红素），后者是"我在照护什么"（管子 + 引流）。合成一页会让带管居家的记录被症状描述淹没——用户操作的是管子，不是症状。

**为什么「报告清单」放 `labs` 而不是新开第 10 页**：一级页固定 9 个是家族一致性要求（R0）。化验单是报告的主体，影像/病理/出院小结在这里只做**文件索引**（一行一份、标是否进趋势）；`imaging` 页继续做影像的**结构化事实**（病灶、淋巴结、受侵范围）。两者不重叠：一个是"有哪些纸"，一个是"纸上写了什么结构化的东西"。

**为什么「方案依据」放 `treat` 的二级而不是新页**：依据讨论天然依附于某一次方案变更，脱离线序单独成页会变成一份没人回看的档案。
