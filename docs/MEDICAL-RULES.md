## 为什么现在做这件事

G2 还在逐页走查（12 页走了 2 页），业务代码（`src/`）按纪律不能开写。但 M2–M9 每一条都会在写代码时反复被问到——
与其等到实现时凭记忆，不如现在把它们变成对**原型 + 演示数据 + schema** 的可执行判据。
原型是当前唯一的"运行时"，规则先在这里立住，迁到 `src/` 时是平移而不是重新理解。

## 这条路子的边界（别把它当临床验收）

1. **M5 是近似**：能证明"没有判定函数、没有判定用语"，证明不了"没把判定藏进文案"。文案层面的判断仍需人读。
2. **词表检查只看字面**：换个说法（"比上次好一些"）不一定命中。所以 `check-wording.mjs` 与本脚本是两道网，不是一道锁。
3. **只覆盖原型与演示数据**：`src/` 落地后，同一套规则要指向真实读模型；届时切片名（`vDash` 等）要换成模块名。
4. **M1 / M10 / M11 / M13 未纳入**：M1（分级只用对照）与 M13（试验三态）需要"结构"而非"词表"才能判，
   等 T06 把匹配引擎抽成纯函数后再补单元测试；M10/M11 目前靠 `check-wording.mjs` + 人工走查。
